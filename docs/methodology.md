# 整理方法与核查范围

本仓库是围绕 agentic 安全训练与验证的定向资源地图，不是穷尽领域的系统综述，也不是排行榜。核心问题是资源能在什么环节帮助使用者，以及其证据能够支撑什么结论。

## 选取与来源

首版 27 项来源来自主题关键词检索、相关工作的局部引用扩展及原文直接链接。关键词搜索和引用扩展没有穷尽所有命中；一个参考列表受限，部分前向引用只读了首批结果。因此，未收录不代表不存在，未报告不代表无效果。

文献判断以原始研究博客和论文正文为依据。论文若只核对预印本，就保留该状态；索引中的会议标签不等于已核对正式同行评审版本。条目的源链接指向上游原文，不指向本仓库自写总结。

## 可用性层次

- **论文／方法已定位**：可以了解设计，不能自动视为可运行工具。
- **仓库或数据卡已核查**：已检查说明、文件入口或部分许可，不等于完成实现审计。
- **独立复现**：需实际运行并记录版本、配置、结果。本首版所有条目均未独立复现。
- **再发布资格**：需要上游、导入子集及生成来源的许可足以覆盖拟议用途；根许可证不能替代全部核查。

公开资源核查主要覆盖仓库 README、文件树、部分根许可证、核心数据卡与少量生成脚本。没有下载完整第三方训练数据或模型；没有逐文件审计依赖、上游子集与生成服务条款。若资源没有根许可证或补充数据卡未读取，保留未核查状态，不推断为禁止使用或资源不存在。

## 证据边界

区分文本回答、选择题、模拟工具状态、隔离的真实工具服务和真实部署。分别报告或保留实际行动、任务完成、授权、误拒绝、一般能力与后续学习保持性；任何一项缺失都不由另一项代替。

多模型分别调参后有效，不能自动证明冻结默认配方的低成本复用。安全 RL 后保持不能自动外推到能力 RL；某个故事数据分布的负结果不能外推全部安全教育。

## 数据维护

`data/resources.json` 是机器可读主索引，`data/resources.csv` 是便于筛选的视图，`docs/` 提供按作用分组的说明。首版核查日期为 2026-10-01，整理日期为 2026-10-03。有纠错时应同时更新相关条目及说明，并留下明确修改记录。

这份资源地图不能代替机构安全审查、数据许可判断或部署时的权限隔离。
