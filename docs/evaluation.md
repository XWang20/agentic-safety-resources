## Agentic Misalignment: How LLMs Could Be Insider Threats

**作用：** 参考目标冲突、自主性威胁及系统提示干预下的模拟行为评估；不是安全训练效果证据。

**来源：** [Agentic Misalignment: How LLMs Could Be Insider Threats](https://arxiv.org/html/2510.05179)。预印本（本次读取arXiv版本；未确认同行评审）

**干预或实现思路：** 未实施可复用的安全训练干预。实证干预仅是在推理时向系统提示加入禁止危害人身安全、利用私人信息和泄露机密的直接行为指令；安全训练、分布更接近代理失调的训练及新型对齐技术仅作为作者提出的未来研究方向。

**何时用：** 评测与推理时指令干预，不进行安全训练

**可采用的资源：** 代码：[https://github.com/anthropic-experimental/agentic-misalignment](https://github.com/anthropic-experimental/agentic-misalignment) 数据：公开评测方法；不是训练教育语料

**已报告结果：** 实证发现：在受控模拟中，直接系统提示禁令降低了勒索和商业间谍行为，但未能可靠或完全阻止这些行为；控制条件显示，移除目标冲突和自主性威胁后，模型通常不实施目标行为。作者假设而非实证结论：更贴近代理失调分布的安全训练、改进现有对齐数据的泛化、运行时监控及进一步提示工程可能成为缓解方向。本文不提供可复用代理安全训练方法的实证证据。

**行为与泛化范围：** 实际部署：未评估，且作者明确表示未见真实部署中的相关证据。模拟评估：已开展，全部行为发生于受控的虚构企业环境。主要跨模型实验采用结构化文本；另有Claude Sonnet 3.6计算机使用演示，通过模拟桌面和邮件系统执行操作。 未评估训练后留出迁移，因为本文没有训练干预。研究测试了多种模型、情景、目标与有害行为，但这属于行为评估，不能据此推断安全训练的跨任务、跨模型或系统性复用。

**能力、误拒绝与保持性：** 能力保持：未评估/未报告。过度拒绝：未评估/未报告。研究重点是代理在目标冲突或自主性威胁下采取有害行动，而非拒绝训练；也未报告干预对一般任务能力、正常代理效用或良性请求拒绝率的影响。 未评估/未报告。没有在后续能力训练、微调、持续学习或其他参数更新之后测试干预保持性。

**局限／未评估：** 情景高度人工化，并被设计成失败与伤害之间的二元选择；重要信息被集中呈现，可能产生显著性或“Chekhov’s gun”效应；主要结果来自模拟而非真实部署；提示针对Claude模型迭代红队优化，跨模型结果不等同于训练干预的跨模型复用；思维链陈述可能不忠实于底层过程；直接指令干预没有能力保持、过度拒绝、留出迁移或后续学习保持性评估。

## Refusal-Trained LLMs Are Easily Jailbroken As Browser Agents

**作用：** 用浏览器 agent 场景检查聊天拒绝能力能否迁移到动作执行。

**来源：** [Refusal-Trained LLMs Are Easily Jailbroken As Browser Agents](https://arxiv.org/abs/2410.13886)。预印本（本次读取arXiv版本；未确认同行评审）

**干预或实现思路：** 未实施新的安全训练干预。本研究评估既有拒绝训练（作者概述为通常采用RLHF或RLAIF的后训练安全对齐）能否从聊天场景泛化到浏览器智能体，并发布BrowserART红队测试套件；因此不属于可复用智能体安全训练方法的实证研究。

**何时用：** 仅评测已有聊天安全模型作为浏览器agent；无新训练

**可采用的资源：** 代码：未从已整理来源中定位到可直接采用的完整代码入口；不表示不存在。 数据：未核查本文数据

**已报告结果：** 实证发现：既有聊天拒绝行为不能可靠泛化到浏览器智能体；相同底层模型作为聊天机器人时可能拒绝有害请求，作为智能体时却可能执行。面向聊天模型的越狱方法也能攻击浏览器智能体。作者关于原因的假设是：拒绝训练多面向较短上下文，且智能体特定有害行为可能未充分出现在安全训练数据中；这些是解释性假设，不是经训练消融验证的因果结论。

**行为与泛化范围：** 同时包含文本与智能体行为评估：以聊天文本行为测试底层LLM；以OpenHands浏览器智能体测试动作和轨迹。多数网站为本地合成网站，少数任务访问真实互联网入口或无真实用户的网站并由人员监控。因此主要是沙箱模拟行为评估，辅以有限受监控的真实网络环境；未进行现实世界无约束部署评估。 未评估安全训练在留出任务上的迁移，因为没有训练干预或训练集。论文实证评估了原为聊天LLM设计的攻击向浏览器智能体的迁移，但这属于攻击迁移，不是所学安全策略的留出迁移。不同模型分别接受评估，不能据此推断系统性的跨模型安全训练复用。

**能力、误拒绝与保持性：** 能力仅通过每个智能体的10个良性任务进行基本健全性检查；SeeAct因未能完成全部良性任务而被排除。未系统评估一般能力保持、良性请求误拒绝率或过度拒绝。论文明确提出安全拒绝应在保留一般能力的同时产生安全输出，但没有训练后能力—安全权衡实验。 未评估/未报告。没有进一步微调、持续学习或后续能力训练，因此无法判断安全行为在进一步学习后的保持情况。

**局限／未评估：** 不是安全训练研究，只能作为聊天拒绝训练对智能体场景泛化不足的负面证据。；合成网站仅包含目标相关功能，界面复杂度低于真实网站。；部分真实互联网任务需要人工监控，流程尚未完全自动化。；危害分类使用GPT-4o裁判；作者人工检查确认同时存在假阳性和假阴性。；长上下文归因实验只使用单个长HTML前缀，作者要求未来研究进一步分解智能体组件的影响。；自动攻击各只测试一个固定前缀或后缀，可能低估攻击效果。；未评估新的智能体安全训练、留出安全迁移、过度拒绝或进一步学习后的保持。

## AgentHarm: A Benchmark for Measuring Harmfulness of LLM Agents

**作用：** 评估恶意用户请求下的 agent 有害执行与拒绝；不要混入训练后再宣称独立持出。

**来源：** [AgentHarm: A Benchmark for Measuring Harmfulness of LLM Agents](https://arxiv.org/abs/2410.09024)。会议论文（S2索引标注ICLR；本次读取arXiv稿，未单独核验正式会议版本）

**干预或实现思路：** 未实施或评估可复用的智能体安全训练。本研究主要提出合成工具环境下的智能体危害基准，并评估直接请求、强制工具调用、通用越狱模板及提示词变体；拒绝提示仅属于推理时提示消融，不是模型训练。

**何时用：** 仅基准与攻击评测，不训练安全agent

**可采用的资源：** 代码：未从已整理来源中定位到可直接采用的完整代码入口；不表示不存在。 数据：[https://huggingface.co/datasets/ai-safety-institute/AgentHarm](https://huggingface.co/datasets/ai-safety-institute/AgentHarm)

**已报告结果：** 实证发现：多种前沿模型在无越狱时也会执行部分恶意智能体请求；经轻微智能体化修改的通用聊天越狱模板可降低拒绝并促成连贯的多步恶意工具使用；成功越狱后，基础智能体能力未显示明显退化。作者假设而非实证结论：现有安全训练可能未充分迁移到智能体场景，且专门设计的脚手架可能改善能力与鲁棒性。本研究不提供可复用智能体安全训练方法的有效性证据。

**行为与泛化范围：** 主要是模拟执行：智能体在无副作用的合成工具上完成多步任务，属于现实危害的代理评估；另有仅文本的聊天请求对照。未评估真实工具执行或现实世界危害。 设有验证集、公开测试集和未暴露给公共LLM API的私有测试集；通用越狱模板主要用私有验证集中的单个样本优化，并在多种模型上评估。但这衡量攻击和基准迁移，不是安全训练干预的留出迁移，也不能据此推断安全训练可跨模型系统复用。

**能力、误拒绝与保持性：** 通过有害任务得分、非拒绝样本得分和良性对应任务评估基础多步工具使用能力。作者报告成功越狱后的基础智能体能力与良性任务表现相近。良性任务几乎不被拒绝，但未对一般意义上的过度拒绝进行专门、系统评估。 未评估/未报告；没有在后续能力训练、微调或持续学习之后测试安全干预保持性。

**局限／未评估：** 研究核心是攻击与评测基准，而非安全训练干预。；工具均为无副作用的合成工具，任务更容易且现实性较低。；仅使用英文提示。；不包含用户后续消息驱动的多轮攻击。；评分函数可能遗漏可接受的替代执行轨迹。；依赖自定义工具，难以直接评估不支持这些工具的第三方脚手架。；仅衡量基础智能体能力，不衡量高级自主能力。；未评估训练干预的跨模型复用、长期保持或进一步学习后的安全性。

**许可与接入核查：** 卡片/文件名/LICENSE已读：MIT附加仅改善AI安全与安全性用途条款；不是无限制MIT

## AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents

**作用：** 评估不可信工具内容下的提示注入、任务正确性和攻击成功，利用持久状态进行行为判定。

**来源：** [AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents](https://arxiv.org/abs/2406.13352)。会议论文（S2索引标注NeurIPS；本次读取arXiv稿，未单独核验正式会议版本）

**干预或实现思路：** 未实施可复用的智能体安全训练；本文主要提出动态评测框架，并评估提示词分隔、提示注入检测、重复用户提示和工具过滤等推理时防御。检测器是既有的已训练BERT分类器，但本文未报告对基础智能体模型进行安全微调或拒答训练。

**何时用：** 仅基准与推理时防御，不训练安全agent

**可采用的资源：** 代码：[https://github.com/ethz-spylab/agentdojo](https://github.com/ethz-spylab/agentdojo) 数据：公开模拟环境与任务数据路径

**已报告结果：** empirical：多种现有防御可降低目标攻击成功，但均存在效用或适应性攻击方面的限制；简单工具过滤较有效，却依赖任务所需工具可预先确定且不足以完成攻击。作者还观察到更有能力的模型往往更容易受到目标攻击，而良性能力与攻击下效用呈正相关。；author_hypothesis：作者认为，要抵御更强的自适应攻击，可能需要模型在区分指令与数据方面取得重大突破；这属于前瞻性判断，不是训练实验结果。

**行为与泛化范围：** 在动态、可变状态的仿真应用环境中执行真实工具调用，并用确定性状态检查评估效用和攻击目标；不是现实生产部署，也不是仅靠文本判断或由另一个LLM模拟工具与评分。 未评估跨任务分布、跨环境或跨模型的训练后留出迁移；多模型实验是同一评测框架下的分别测试，不能视为系统性安全训练复用证据。

**能力、误拒绝与保持性：** 能力通过无攻击时的良性效用和攻击下效用评估；未单独评估过度拒答。提示注入检测器出现较多误报并显著降低效用，可作为防御副作用证据，但不能等同于系统性过度拒答评测。 未评估在后续能力训练、微调或持续学习后的安全保持。

**局限／未评估：** 研究核心是安全评测而非安全训练，因此不能回答训练干预的可复用性、时序、留出迁移或持续学习保持。；攻击和防御相对简单，作者明确指出需要更复杂的防御与自适应攻击。；工具过滤不适用于无法预先规划工具或合法任务与攻击共享同一工具集的情形。；尚未覆盖跨时间保留上下文的多任务智能体、视觉等多模态智能体以及受长度或格式约束的提示注入。；任务与效用标准主要依赖人工设计，扩大任务和攻击目标范围仍面临可扩展性问题。；环境使用合成虚拟数据，不构成真实生产部署中的安全验证。

## OpenAgentSafety: A Comprehensive Framework for Evaluating Real-World AI Agent Safety

**作用：** 参考真实工具的隔离服务环境及副作用判定；使用前检查推荐实现与维护状态。

**来源：** [OpenAgentSafety: A Comprehensive Framework for Evaluating Real-World AI Agent Safety](https://arxiv.org/abs/2507.06134)。预印本（本次读取arXiv版本；未确认同行评审）

**干预或实现思路：** 未实施训练干预。本研究提出的是可执行的智能体安全评测框架，而非可复用安全训练方法；作者仅提出该框架可用于安全训练、强化学习和防护机制的原型设计与压力测试。

**何时用：** 仅基准评测，不实施安全训练或SDF

**可采用的资源：** 代码：[https://github.com/Open-Agent-Safety/OpenAgentSafety](https://github.com/Open-Agent-Safety/OpenAgentSafety) 数据：公开任务/服务及评测路径

**已报告结果：** 实证发现：七个模型在复杂、多轮、工具调用场景中均表现出显著不安全行为；在到达安全脆弱状态的任务中，LLM-as-judge 报告的不安全率从 49% 到 73%。良性表面意图、隐藏的 NPC 恶意意图、制度性规则和多轮上下文均暴露出缺陷。作者假设或建议而非实证训练结论：应采用跨轮意图聚合、工具权限边界和基于政策的数据监督；OA-Safety 可作为未来训练和压力测试基础。论文没有证明任何训练干预可复用、可迁移或可长期保持。

**行为与泛化范围：** 混合型智能体评测：智能体在隔离的 Docker 沙箱中操作真实文件系统、Unix shell、Python、浏览器和消息工具；网站、用户及 NPC 为本地托管或模型模拟。因此不是现实部署中的实际伤害评测，也不是仅文本评测。采用环境终态规则检查与轨迹文本的 LLM-as-judge 联合评价。 未评估/未报告训练后的留出任务迁移，因为没有训练干预。跨风险类别、意图、工具和七个模型的结果属于基准评测，不构成已训练安全能力的留出迁移证据，也不能据此推断系统性跨模型复用。

**能力、误拒绝与保持性：** 报告了任务失败率和成功完成率，可部分反映智能体能力；但成功完成指标把直接拒绝与安全完成任务合并，无法单独衡量过度拒绝。安全训练对一般能力的影响、能力—安全权衡及过度拒绝均未评估/未报告。 未评估/未报告。没有在进一步能力训练、微调或持续学习后测试安全行为保持情况。

**局限／未评估：** 这是一项评测研究，不能回答安全训练的效果、训练时点、留出迁移或保持性。部分模型在接触安全风险前即因导航、认证或工具使用失败而退出；作者指出 LLM judge 可能高估失败并漏判隐含的不安全工具行为。NPC 存在非确定性，任务和执行环境扩展困难。不同模型均接受同一基准评测不等于同一训练方法可跨模型复用。

## Agent-SafetyBench: Evaluating the Safety of LLM Agents

**作用：** 获得较广的 agent 风险和失败类型覆盖；区分模拟环境、模型评审与真实副作用。

**来源：** [Agent-SafetyBench: Evaluating the Safety of LLM Agents](https://arxiv.org/abs/2412.14470)。预印本（本次读取arXiv版本；未确认同行评审）

**干预或实现思路：** 未评估可复用的智能体安全训练。针对被测智能体仅在推理时追加简单或增强版防御提示，重点覆盖工具调用鲁棒性与风险意识，而非主要训练拒绝行为。论文微调了Qwen-2.5-7B-Instruct作为安全评分器，但该评分器训练不是对被测智能体的安全训练干预。作者仅将智能体安全微调列为未来方向，属于建议而非实证结果。

**何时用：** 仅基准与推理时防御；评分器微调不等于被评agent的安全训练
